# 安然期 Anranqi

面向 45-60 岁围绝经期及绝经后女性的移动端 H5 身体记录工具。

安然期不是另一个普通经期 App。它更关注女性在围绝经期及绝经后阶段真实会遇到的身体变化：经期不规律、较长间隔后再次出血、潮热盗汗、睡眠受影响、身体感受变化，以及就医时“说不清楚”的沟通困难。

## 产品定位

安然期是一款个人身体记录与就医沟通辅助工具，帮助用户：

- 记录经期变化、出血量、颜色、腹痛和备注
- 记录潮热盗汗、睡眠受影响、身体感受和整体心情
- 回看变化日历与近 30 天趋势
- 生成近 90 天就医摘要，方便给医生快速了解情况

产品只做记录、观察和沟通辅助，不做医学诊断，也不提供治疗方案。

## 为什么做这个产品

主流女性健康 App 往往更关注年轻女性、规律经期、备孕、怀孕和社区内容。  
但 45-60 岁女性进入围绝经期后，需求会发生变化：

- 周期预测不再是核心，身体变化记录更重要
- 较长时间后再次出血需要被温和标记
- 潮热、盗汗、睡眠和私密不适更常见
- 去医院时需要一份清晰摘要，而不是零散回忆
- 用户更需要大字号、大按钮、低刺激、少打扰的界面

安然期的稀缺性在于：它不是把年轻经期 App 改个颜色，而是从围绝经期及绝经后女性的真实场景重新组织产品结构。

## 核心亮点

### 1. 面向特定人群

服务对象明确为 45-60 岁围绝经期及绝经后女性，而不是泛女性经期管理用户。

### 2. 三个主栏目，降低认知负担

底部只保留：

- 今日记录
- 变化日历
- 就医摘要

不做社区、商城、内容流和复杂运营入口，让产品保持安静、清晰。

### 3. 温和文案，不制造焦虑

产品避免诊断化、恐吓化表达。例如：

- “异常出血”改为“较长间隔后再次出血”
- “睡眠差”改为“睡眠受影响”
- “高频身体不适”改为“常被记录的身体感受”
- “无出血 / 有出血”改为“今天没有 / 今天有出血或点滴”

提醒语统一采用“建议关注”“必要时咨询医生”等克制表达。

### 4. 为 50+ 用户放大字号与点击区域

界面采用移动端优先设计：

- 正文 17px 起
- 标题 22px-24px
- 按钮 17px-18px
- 大卡片、大按钮、低信息密度

目标是看得清、点得准、用得安心。

### 5. 私密不适的克制表达

将“泌尿与私密不适”调整为“私密不适”，并使用更生活化选项：

- 小便次数变多
- 小便比较急
- 私处干涩感
- 私处不舒服
- 皮肤干痒
- 口腔不适
- 自定义

私密选项采用横向滑动，并提示数据仅保存在本机，降低用户心理压力。

### 6. 就医摘要带“依据”

就医摘要不是简单给出提示，而是同时说明触发原因：

> 提示：近期盗汗对睡眠有影响，可以记录发生时间和频率，必要时咨询医生。  
> 依据：有 2 天记录夜间出汗醒来。

这样既能提醒用户，也避免莫名焦虑。

### 7. 首次引导逐题出现

首次使用不是一次性填写复杂表单，而是逐步询问：

1. 年龄段
2. 经期当前状态
3. 经期较长间隔提醒

后续也可以在设置中重新调整基础信息。

## 技术实现

- React
- Vite
- localStorage
- 移动端优先 H5
- 无后端
- 无登录

当前版本是可交互 Demo，适合用于作品集展示、产品评审、用户访谈和原型验证。

- Framework Preset: `Vite`

- Output Directory: `dist`

项目已包含 `vercel.json`，Vercel 通常会自动读取配置。

## 数据说明

当前版本为前端 Demo，数据保存在用户本机浏览器的 `localStorage` 中。  
如果作为正式产品上线，还需要补充账号系统、云端同步、隐私政策、数据删除机制和医学合规审查。

## 项目价值

这个项目验证了一个更细分、更温和的女性健康记录方向：  
不是追求功能堆叠，而是围绕特定阶段女性的真实身体变化、心理压力和就医沟通困难，设计一个小而清晰、低刺激、可信赖的记录工具。
